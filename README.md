# PAC-MAN: Neon Arcade Edition

### Introduction

A browser-based Pac-Man clone built with plain HTML, CSS, and JavaScript. It includes a menu flow, multiple maze levels, AI-controlled ghosts, score tracking, power-ups, sound, and local high-score persistence.

### Tech Stack

- HTML5
- CSS3
- JavaScript ES modules
- Node.js test runner for gameplay checks

### Features

- Classic Pac-Man gameplay loop with eating pellets and avoiding ghosts
- Multiple generated levels with increasing difficulty
- Ghost behaviors including chaser, ambusher, predictive, and patroller patterns
- Power-ups such as speed boosts, shields, double points, slow ghosts, and extra lives
- Pause menu, level select screen, and how-to-play instructions
- High-score saving using browser local storage
- Keyboard and mobile controls
- Lightweight setup with no build step required

### How to Play

- Move: W/A/S/D or arrow keys
- Pause: P
- Menu interaction: mouse / touch
- Mobile: use the on-screen D-pad below the game area or just swipe
